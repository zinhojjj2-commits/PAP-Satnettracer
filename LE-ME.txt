COMO ABRIR
1. Extrai a pasta do ZIP.
2. Mantém a pasta css e a pasta js junto do index.html.
3. Abre o index.html num navegador (Chrome, Edge ou Firefox).

NOTAS IMPORTANTES
- Os ficheiros JavaScript estão numerados porque dependem uns dos outros.
  Não alteres a ordem das etiquetas <script> no index.html.
- O projeto continua a carregar os tipos de letra do Google Fonts através da Internet.
- Não apagues nem mudes os IDs/classes do HTML sem rever o JavaScript:
  o código procura muitos elementos através desses identificadores.
- O código original foi separado por ficheiros, sem reescrever a lógica da aplicação.
